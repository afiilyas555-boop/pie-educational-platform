# 🚀 PIE

## 📌 About

**PIE** is an educational website created as part of the **Programme d’Innovation Entrepreneuriale (PIE)** at OFPPT.

This project was created to provide an alternative to the **traditional methods used to present and share the content of this module**.

The main goal is to make the learning experience easier, more organized, and more accessible for current students, while also creating a useful resource for **future trainees who will study this module after us**.

Instead of depending only on traditional presentations, the website brings the module's content and learning resources together in one accessible platform.

---

## 🎯 Project Purpose

The project was developed with two main objectives:

### 👨‍🎓 For Current Trainees

* Make the module easier to understand and review.
* Organize the learning content in a simple way.
* Provide quick access to presentations and educational resources.
* Make learning more interactive through videos and digital content.

### 👥 For Future Trainees

The website can remain available as a learning resource for students who will study the module in the future.

This allows future trainees to:

* Review the content independently.
* Access previous learning resources.
* Discover entrepreneurial success stories.
* Use the website as a complementary resource during the module.

---

## ✨ Features

* 🏠 **Centralized Interface**

  * All main resources are accessible from one website.

* 📚 **Educational Content**

  * Organized content related to the PIE module.

* 🚀 **Entrepreneur Stories**

  * Stories and experiences of different entrepreneurs.

* 🎥 **Educational Videos**

  * Videos integrated into dedicated pages.

* 📄 **PDF Resources**

  * Direct access to module support documents.

* ⛶ **Full-Screen PDF**

  * Possibility to view PDF resources in full screen.

* 🖱️ **Interactive Navigation**

  * Dynamic navigation designed to make browsing easier.

* 📱 **Responsive Design**

  * Adapted to different screen sizes.

## 💡 Why This Project?

Traditional presentations are useful, but they can be limited because the information may remain available only during the presentation or inside separate documents.

With **PIE**, the objective is to create a digital space where the content can remain accessible and useful beyond the original presentation.

The website therefore acts as a **digital learning resource** that can be used by both current and future trainees.
